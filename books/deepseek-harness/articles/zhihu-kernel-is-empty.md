# 一个开源项目的内核是空的——连 agent 循环都只是个插件

家里厨房的灯不亮了，叫个修灯师傅。

师傅到了，拎着一整套家伙：螺丝刀、万用表、梯子，还有个小本子。

先问一句：师傅最值钱的，是那套家伙，还是那颗脑子？

是脑子。螺丝刀谁都会拿，知道先拆哪一颗才难。

再反过来想：一个人只有脑子，没有手，修得好灯吗？修不好。他说「先断电，再拆开看看」，没人动手，等于没说。

大模型现在就是这个处境。它知道该怎么干，但它自己够不着——它打不开你的终端，读不了你的文件，按不了你的确认键。所以想让它干活，得给它配一整套人马。

这篇文章讲一个叫 DeepSeek Harness（下称 DSH）的开源项目。它的做法是：把这套人马里的每一个岗位，包括发号施令的那个，全部改成临时工。

## 每套软件里，都有个动之前得开会的地方

可能是订单主流程，可能是登录模块，可能是那段谁也不敢碰的历史代码。它未必是写得最好的部分，但一定是最难换的部分。改一次，别的模块跟着抖三抖。

大模型外壳这类软件，「谁敢动」的答案向来明确：循环。

就是那个「看情况 → 决定 → 动手 → 看结果 → 再决定」的循环。模型提一句，外壳执行一步，把结果喂回去，模型再提下一句。整个系统的节奏全听这个循环的。

大多数系统把循环焊死在公司最里面。这个选择有道理：循环换了，整个队的作风都变了，想让行为一致，就得把它攥在自己手里。代价也清楚：外面的人想要另一种节奏，只能等官方更新。等不到，就只好自己再开一家公司，重新雇一遍人。

Claude Code、Codex CLI，都是这么干的——它们给你一个成品，循环是人家设计好的，你用，但改不了。这是卖成品的思路。

DSH 反过来。循环也是临时工，它和拧螺丝的、记笔记的站在同一层，由同一张排班表决定今天谁上。

## 领班也是临时工

DSH 的中心那一层，可以整块拿走，别处一行都不用改。

凭什么？

它核心机制只有两条。

第一条，内核只留原语：时钟怎么取、日志往哪写、崩溃留不留现场。这些哪家做法都差不多，换不出花样。留着它们，系统才有个稳的底子。

第二条，其余一切都是插件。模型适配器、工具注册表、会话日志，以及 agent 循环本身，全由一份装配清单决定当前会话装哪些。官方的说法是：产品的每一部分都是插件，包括模型适配器、工具注册表、会话日志，以及 agent 循环本身；不存在需要打补丁的特权内核。

插件之间不互相直连。消费方按名字要能力，装配层照着清单把名字兑现成实现。所以加一样能力，等于在清单里登记一行，内核一行不动。

打个比方。左边那种公司，中心部门被六个科室直接点名对接——财务直接找小张，采购直接找小张，库房直接找小张。小张一请假，全公司瘫。右边那种公司，谁都不知道「小张」是谁，只知道名单上有一行「出纳岗」；今天小张上，明天李四上，换人只改那一行。

「能不能换」因此可以量化：换掉它要动几个地方，这个数字叫改动半径。DSH 的 agent 循环在右边，改动半径是一行配置。

## 三种外壳，三种卖法

把三家摆在一起看，区别一句话能说完：

Claude Code 卖成品。开箱即用，体验打磨到牙齿，但循环是它的，你租用。

Codex CLI 卖接口。轻、快、终端原生，核心能力摆在明面上，但深度定制同样受限。

DSH 卖插座。它不预设你要哪种循环、哪些工具，它把「怎么装」这套机制本身交给你。

没有对错，只有愿意拿什么换什么。要稳定和省心，成品是理性选择；要能长出自己的东西，插座才是。

## 「空」骗了不少人

「一切皆插件」最容易被理解成两件事，都是错的。

第一，理解成「每个位子都有备胎」。它讲的是一件更窄的事——加一样能力，不必改内核。至于那个位子上有没有第二个实现可换，得看具体位置。

第二，理解成「没有中心」。中心还在，只是里面只放换了没意义的原语。空的是特权，不是地方。

还有个更隐蔽的：工牌上印着「灵活编制」不算数。有的公司，工牌都写 flexible，可全公司每个人还是直接点名找那个小张。小张一请假，全公司瘫。声明可插拔和真能替换，中间隔着一条街。

## 两个能搬走的自查

这篇文章真正想给的，是判据，不是八卦。

第一，挑出你的系统里那个「一请假全瘫」的组件，数一数有多少处直接写了它的名字。数字越大，替换越是空话。

第二，判断一个组件该不该进内核，问的不是它重不重要，是它会不会被换。重要会骗人。财务系统很重要，可很多公司真换过财务系统；法务也很重要，同样换过。重要却很少被动的东西，才该待在内核里。

拿这两条去量你自己在维护的项目——先别量 DSH，量你自己的。数出来的数字，比这篇文章更值钱。

## 代价也得说

把一切都请出内核，不是白来的。

代价一：装配清单自己不干活。读一遍清单，看不出系统在干什么，行为得从配置里重建。复杂度从实现方转移给了使用者。

代价二：读的人成本变高。系统内部干净了，但「看懂它在干什么」这件事往前挪了一步——你得先读懂那张排班表。

换来的是：换得动，且内核不长胖。想要另一种循环，不必等官方，不必 fork 重来。

两条路没有对错，只看愿意拿什么换什么。DSH 选了后者，并且选得很干净——干净到连循环都不要了。
